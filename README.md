# Thinh Hung Ho — portfolio + engineering notes

Personal portfolio and blog for Thinh Hung Ho, Senior AI Engineer.

## Personalize it

1. Add a new file inside `_posts/` named `YYYY-MM-DD-your-post-title.md`.
2. Add the title, subtitle, and date in the front matter.
3. Write the post in Markdown and push to GitHub.
4. In repository settings, open **Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.

Posts use Markdown and support normal Jekyll front matter:

```yaml
---
title: "Your post title"
subtitle: "A short description"
date: 2026-08-12
---
```

The first version is designed to run from `hungho77.github.io/hung/`. If you later create `hungho77.github.io`, set `baseurl` to an empty string in `_config.yml`.
